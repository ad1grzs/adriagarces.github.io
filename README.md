# adriagarces.github.io

Personal site (Jekyll, no remote theme).

- `index.md` lists the modules in order.
- `_includes/sections/` one file per section (hero, intro, education, notes, projects, publications, contact).
- `_data/` all the content (profile, education, notes, projects, publications) in YAML.
- `assets/css/style.scss` design tokens (colors) and styles; `assets/js/main.js` menu, scroll highlight and hero animation.
